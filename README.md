# DIGIADUL

Prototipo web progresivo accesible para fortalecer las competencias digitales y promover el uso responsable de la inteligencia artificial en adultos mayores de Medellín.

## Propósito

DIGIADUL busca apoyar la alfabetización digital mediante contenidos claros, navegación sencilla, actividades prácticas y orientaciones sobre seguridad digital, privacidad y uso responsable de herramientas de inteligencia artificial.

## Alcance de esta fase

En esta fase se organiza el trabajo Scrum, se define la estructura del producto y se prepara el prototipo funcional para su validación. El alcance corresponde a un prototipo académico; no incluye autenticación real, base de datos productiva, procesamiento de información personal ni un modelo propio de inteligencia artificial.

## Módulos previstos

1. Dispositivos digitales.
2. Internet y correo electrónico.
3. Inteligencia artificial responsable.
4. Seguridad digital.

## Organización Scrum

El tablero de trabajo y el Product Backlog se encuentran en [DIGIADUL - Scrum Fase 4](https://github.com/users/GabrielCastrillon/projects/2). Las actividades están organizadas en Sprints 0 a 4 y se gestionan mediante Issues del repositorio.

## Tecnologías previstas

- HTML5, CSS3 y JavaScript.
- Diseño adaptable para computador, tableta y celular.
- Manifest y Service Worker para el comportamiento de aplicación web progresiva.
- Criterios de accesibilidad, usabilidad, seguridad y lenguaje claro.

## Estado

Proyecto académico en construcción. Las funcionalidades se implementarán y validarán progresivamente según el Product Backlog y los criterios de aceptación registrados en GitHub Issues.
